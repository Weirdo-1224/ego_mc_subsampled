# 六组实验准备计划

E1–E6 是本次准备阶段提出的分组，现有总体设计稿没有指定这六个编号。
每组的 `plan.json` 记录问题、Track、候选对照和前置门禁，全部 `DRAFT`、`enabled: false`。
这些文件是计划清单，当前没有实验执行器，也没有模型调用入口。

| 组 | 目的 | Track |
|---|---|---|
| E1 | 近期窗口与历史基线 | T1/T2/T3 |
| E2 | 状态与记忆管理消融 | T1 |
| E3 | 前置约束，区分要求与实际完成 | T2 |
| E4 | 多段历史与规则修订 | T3 |
| E5 | 可见性、专家反馈与语言捷径 | T1/T2/T3 |
| E6 | 新来源接入与预算稳健性 | T1/T2/T3 |

窗口、容差、历史跨度和预算均待开发集校准；不得把初始建议当作冻结协议。
后续每次运行须单独保存配置、输入哈希、代码/模型版本、时间线、成本、异常和评分分母。
