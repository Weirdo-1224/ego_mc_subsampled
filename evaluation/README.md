# 评估边界与后续门禁

目前唯一可运行的检查器是 `python -m benchmark.validate`，只校验数据结构和因果引用。
没有评分器、正式分数或模型结果。`--require-gold` 是数据准备门禁，不会启动评测。

后续 T1 按已审核状态检查点计算质量与更新延迟，T2 计算前置条件判断和证据质量，
T3 按历史必要性、规则有效期和证据链分析；三个 Track 分开报告。
Intervention 如启用，再实现事件一对一匹配、误报/小时、检测延迟与恢复；不得用反馈时刻替代检测起点。

评测开始前必须具备：人工审核的 GOLD 答案、充分/必要证据集、已核验发布时刻、
独立 Probe 分支、未来帧访问阻断、冻结的开发集参数及完整负样本分母。
数据校验不能发现答案文本中所有隐含未来信息，也不能取代视频核验或实际运行沙箱。
