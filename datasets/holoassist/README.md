# HoloAssist 接入准备

当前未下载、未导入，也未核实原始字段和可用模态。接入前确认所获版本、许可、
本地媒体与标注路径，随后新增适配器并在 `configs/datasets.json` 登记。

1. 建立原始文件哈希和定位清单；保留原始交互、动作及参与者标识，不覆盖源标注。
2. 对实际可用的模态建立到 Episode 主时间轴的映射，记录单位、偏移及同步审核结果。
3. 交互文本、指导反馈与执行者实际行为分层映射；专家指出错误不证明错误开始或最早检测时刻。
4. 指令/反馈发布时刻、有效范围、是否构成修订需审核；未知时不进入在线输入。
5. 从核验后的行为建立状态、约束和历史证据链；干预保留 onset/detectable/feedback/resolved 的区别。
6. 按实际参与者、原始任务/会话等关联分组，避免同一过程片段跨集合泄漏。

先交付一个 `CANDIDATE/PENDING` Episode 并运行统一校验；不因数据集已有标签就自动生成 GOLD。
