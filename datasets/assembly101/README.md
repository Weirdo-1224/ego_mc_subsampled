# Assembly101 接入准备

当前未下载、未导入，也未假定其原始字段或时钟格式。接入时先查看实际获得的本地发行文件及许可，
在 `configs/datasets.json` 记录本地根目录，再实现独立适配器。

1. 记录发行版本、文件哈希、许可与原始 Episode/参与者/任务标识，不复制原始视频到派生区。
2. 若有多视角，显式选择主时钟并记录各视角同步关系；不能把多个视角当作独立原始任务随机划分。
3. 将实际动作标注映射为候选 Event；如果只有动作标签，不能自动补出前置条件、对象状态或错误。
4. 经视频核验后构造 T1 状态检查点；T2 约束和 T3 历史依赖需要额外审核与证据链，缺失则保持空表。
5. 按完整原视频、参与者及任务关联进行分组划分，先用同一 Schema 和校验器验证单个准备 Episode。

原始字段名、动作边界可靠性、同步偏移和可支持的 Track 留待真实材料确认。
